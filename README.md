# Proyecto MATEO

Estoy construyendo un Ecosistema SaaS de salud digital para médicos independientes en Perú. Quiero empezar creando la estructura inicial del proyecto. Necesito un panel de control (dashboard) moderno con un tema oscuro elegante y acentos en verde clínico. El dashboard debe tener una barra lateral (sidebar) fija a la izquierda con las siguientes pestañas: Dashboard Principal, Calendario de Citas, Fichas Clínicas (EHR), Recetario Inteligente y Facturación. Por ahora, muéstrame una interfaz limpia y responsiva con componentes de marcador de posición (placeholders) para cada pestaña, siguiendo el estilo modular de plataformas médicas de alta gama como SIVSA HOSIX.
